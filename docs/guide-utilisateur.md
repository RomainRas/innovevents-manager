# Guide d’utilisation — Innov’Events

Site : https://innovevents.rascleromain.fr — application mobile : https://innovevents.rascleromain.fr/mobile/

Les comptes de démonstration (Chloé, administratrice ; José, employé ; Alice, cliente) et leur mot de passe sont transmis séparément avec le rendu : ils ne figurent pas dans le dépôt. Toutes les données de démonstration sont fictives.

## Visiteur (sans compte)

| Je veux… | Où | Comment |
| --- | --- | --- |
| Découvrir l’agence | Accueil | Présentation, réalisations et bouton « Demander un devis ». |
| Voir les événements réalisés | Menu « Événements » | Filtrer par période, type ou thème ; ouvrir un événement pour son détail. Seuls les événements dont le client a accepté la publication apparaissent. |
| Lire les avis | Menu « Avis » | Avis validés par l’équipe. |
| Demander un devis | Menu « Demande de devis » | Remplir le formulaire (entreprise, contact, lieu, type, date, participants, besoin). Un message de remerciement confirme l’envoi ; l’équipe vous recontacte. |
| Poser une question | Menu « Contact » | Titre, description et adresse électronique (ou nom d’utilisateur si vous avez un compte). |
| Créer un compte | « Se connecter », puis « Créer un compte » | Mot de passe : 8 caractères minimum avec majuscule, minuscule, chiffre et caractère spécial. Un courriel de confirmation est envoyé. |
| Récupérer l’accès | « Mot de passe oublié ? » | Un mot de passe temporaire (30 minutes) est envoyé ; choisissez-en un nouveau à la connexion. |

Les pages légales (mentions, CGU, CGV, confidentialité) sont en pied de page.

## Client

Après conversion de votre demande, Innov’Events vous envoie vos identifiants par courriel ; un nouveau mot de passe vous est demandé à la première connexion.

| Je veux… | Où | Comment |
| --- | --- | --- |
| Voir mes prochains événements | « Mon espace » | Les trois événements à venir les plus proches. |
| Consulter un devis | « Mon espace », « Vos devis » | Détail des prestations et totaux ; « Télécharger le PDF ». |
| Répondre à un devis | Sous le devis | « Accepter », « Refuser » ou « Demander une modification » (motif obligatoire), puis confirmer. Une nouvelle version peut vous être proposée. |
| Évaluer un événement | « Évaluer mes événements terminés » | « Donner mon avis » (10 à 2 000 caractères). L’avis est publié après validation par l’équipe. |
| Modifier mes informations | « Modifier mes informations ou supprimer mon compte » | Nom, entreprise, téléphone, adresse. L’adresse de connexion se change via le formulaire de contact. |
| Supprimer mon compte | Même page, « Supprimer mon compte » | Cocher la confirmation, motif facultatif. Vous suivez l’état de la demande ; un courriel confirme la suppression. |

## Application mobile (Chloé, José)

Réservée aux comptes de l’équipe disposant de l’accès mobile.

1. Ouvrir https://innovevents.rascleromain.fr/mobile/ sur le téléphone et se connecter.
2. Installer l’application : Android (Chrome) — menu ⋮, « Installer l’application » ; iPhone (Safari) — bouton Partager, « Sur l’écran d’accueil ».
3. À l’ouverture : la liste des événements à venir. Toucher un événement pour sa fiche (dates, lieu, client, dernières notes).
4. « ＋ Ajouter une note » : saisir puis « Enregistrer ». Sans réseau, le texte reste sur le téléphone.
5. Toucher le client : « Appeler », « Envoyer un courriel », « Itinéraire » ouvrent les applications du téléphone.
6. Sans réseau, les écrans déjà consultés restent lisibles (bandeau « Hors ligne »). « Se déconnecter » efface ces données du téléphone.
