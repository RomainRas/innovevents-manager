## Garde-fous

Pas de nouveaux raffinements visuels tant que les parcours attendus restent manquants. Conserver les maquettes déjà préparées et obtenir leur validation finale. Avancer par blocs utilisables et testés ; actualiser les tâches GitHub avec les réalisations, preuves et limites. Le tableau doit encore être détaillé et priorisé pour couvrir tous les blocs ; le nombre actuel de tickets n’est pas une mesure du pourcentage réalisé.

Le périmètre restant est important. Ce plan ne garantit pas la livraison de toutes les exigences avant l’échéance. Ne pas déclarer un élément terminé parce qu’il est conçu, présent dans le schéma de base ou simulé par un jeu de données. Préparer un bilan factuel des fonctionnalités opérationnelles et des limites du rendu.
